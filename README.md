# 🍔 Food Delivery App UI Design – High-Fidelity

## ✨ Project Overview

This is a **Food Delivery App High-Fidelity UI Design** created using Figma. The application provides a modern and attractive interface for users to explore restaurants, browse food items, place orders, make payments, and track their deliveries.

## 🎯 Objective

The main objective of this project is to design a **user-friendly food delivery application** with a clean, modern, and visually appealing interface that makes ordering food easy, quick, and convenient.
